
# End-to-end SQL analysis with MySQL, Python, Pandas, and Matplotlib.
## Project Overview
This project is an end-to-end data analysis of an e-commerce store dataset using 
MySQL and Python. The dataset consists of multiple relational tables including 
orders, customers, sellers, products, payments, and order_items.

The goal of the project is to answer real business questions related to revenue, 
customer behavior, seller performance, and retention using SQL and data visualization.

## Dataset Description
The dataset contains the following key tables:
- customers
- orders
- sellers
- products
- payments
- order_items
- payments
Each table represents a real-world e-commerce entity and is connected through 
primary and foreign keys.

## Project Workflow
1. Raw CSV files were stored locally on macOS
2. Data was loaded into a MySQL database using Python (mysql-connector)
3. SQL queries were executed from a Jupyter Notebook
4. Query results were fetched into Pandas DataFrames
5. Data visualizations were created using Matplotlib
